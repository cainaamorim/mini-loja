1 · Conectar ao Firebase

Cole o bloco firebaseConfig do seu app Web (fica salvo só neste navegador).

Onde achar: Project settings (⚙) → General → Your apps → app Web → SDK setup and configuration → Config. A apiKey do Firebase pode ficar no navegador; quem protege os dados são as Rules.

Modo simulado: funciona sem internet, guardando tudo no navegador (e sincroniza entre abas). Plano B caso o Wi-Fi caia no briefing.
